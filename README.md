# Rakesh Kumawat — Professional Portfolio

A responsive, static HTML/CSS/JavaScript portfolio website.

## Before publishing
1. Replace the CV at `assets/documents/Rakesh_Kumawat_CV.pdf` if you update your resume.
2. Review all wording, especially the project descriptions and achievement figures.
3. Add a professional headshot if you want one (optional).
4. Confirm your phone number, email and LinkedIn URL.

## Preview locally
Open `index.html` in a browser. For a local development server, use VS Code Live Server.

## Publish free with GitHub Pages
1. Create a GitHub account (or sign in).
2. Create a new public repository named exactly `YOUR-USERNAME.github.io`.
3. Upload all files and folders from this project to the repository root.
4. Open repository Settings → Pages and select Deploy from a branch → `main` → `/ (root)`.
5. Save. Your site will be available at `https://YOUR-USERNAME.github.io` after deployment.

## Notes
- This is a static site; it does not require PHP, Laravel, a database or server-side hosting.
- Replace the repository name with your actual GitHub username.
- External Google Fonts require an internet connection; system fallback fonts are included.
- The project artwork is CSS-generated decorative artwork, not photographs of actual project deployments.

## Resume and certificate section
- Three resume versions are included under `assets/documents/`.
- Three supplied certificates are included under `assets/certificates/`.
- The resume page uses a browser-side password check. This is only a convenience gate, NOT secure access control: GitHub Pages is static hosting, and files in a public repository can be accessed directly by URL or repository browsing.
- Do not use this approach for confidential documents. For real access restriction, use private/authenticated file storage or a backend that checks the password server-side. You can also password-encrypt each PDF as an additional layer.
- The requested password is checked via its SHA-256 digest in JavaScript; the plain password is not stored in the source code.
